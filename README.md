# 🧑‍💻 Responsive User Dashboard

A responsive **User Dashboard Page** built using **HTML, CSS, and JavaScript**.  
This project was developed as part of a Frontend Developer One-Day Interview Task.

---

## 🚀 Features
- Fixed responsive navbar (logo, nav links, and search bar)
- Collapsible sidebar
- Fetches user data dynamically from an API
- Displays user cards with name, email, and status
- Responsive layout (desktop, tablet, mobile)
- Sticky footer

---

## 🧰 Tech Stack
- **HTML5** — Page structure  
- **CSS3** (Flexbox & Grid) — Layout & responsiveness  
- **Vanilla JavaScript** (Fetch API) — Data fetching and DOM updates

---

## 🌐 API Used
User data: `https://jsonplaceholder.typicode.com/users`  
Profile images: `https://i.pravatar.cc/150?img=<id>` (or `randomuser.me` variants)

---

## ⚙️ How to Run

### Option A — Open locally
1. Extract the zip (if zipped).  
2. Open the `user-dashboard` folder.  
3. Double-click `index.html` to open in a browser.

### Option B — Using VS Code Live Server
1. Open the project folder in VS Code.  
2. Install and enable the **Live Server** extension.  
3. Right-click `index.html` → **Open with Live Server**.

### Option C — Hosted (GitHub Pages)
1. Visit: `https://<your-username>.github.io/user-dashboard` (if you enabled Pages).

---

## 📝 Notes
- The user data comes from a public mock API; internet connection required.
- If user cards fail to load, open the browser console (F12) to inspect errors.
